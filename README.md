# Driving School Management System

A web-based Driving School Management System developed using PHP.

## Technologies

* PHP
* MySQL
* HTML
* CSS
* JavaScript
* Bootstrap

## How to Run

1. Install [XAMPP](https://www.apachefriends.org/).

2. Copy or clone this project into the XAMPP `htdocs` folder:

```text
C:\xampp\htdocs\school
```

3. Open XAMPP Control Panel and start **Apache** and **MySQL**.

4. Open phpMyAdmin:

```text
http://localhost/phpmyadmin/
```

5. Import the `database.sql` file into phpMyAdmin.

6. Open the application in your browser:

```text
http://localhost/school/index.php
```
